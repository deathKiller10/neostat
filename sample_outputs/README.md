## Rate-limited (38 files)

The remaining profit & loss statements, cash flow statements, and invoices show
`{"error": {"code": "LLM_RATE_LIMITED", ...}}`. The free-tier API key used to build
this hit Gemini's 20-requests/day cap partway through the full 50-document batch (see
the main README's "Known limitations"). These are kept, not deleted, because they're a
real, honest artifact of the pipeline's error handling working correctly under an
actual rate limit, not a synthetic test case. Running
`python scripts/run_samples.py --skip-existing` again once quota resets will replace
these with real extractions.
